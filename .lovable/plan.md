

# Online Course Dashboard Platform

## Overview
A premium, modern course management dashboard with multiple pages, inspired by the reference screenshot. Clean SaaS-style design with purple accent (#7B61FF), soft shadows, and smooth interactions.

## Pages & Features

### 1. Dashboard Layout (Shared)
- Sticky top navbar with logo, nav items (Dashboard, Community, Events, Courses, Level Up), notification bell with badge, and profile avatar
- Active tab highlighted in purple with underline
- Clean white/light gray background throughout

### 2. Courses Page (Main)
- Page header with title, "Reorder Courses" button, and purple "+ Create" button
- Search bar with icon and category filter dropdown
- 3-column responsive card grid (3 → 2 → 1 columns)
- Course cards with: vibrant gradient thumbnail banners, bold title, metadata (sections • lectures), green "Published" badge, "Edit course" button, 3-dot menu
- Hover effect: slight lift + enhanced shadow
- Dynamic search filtering by title
- Category dropdown filtering

### 3. Course Detail Page
- Full-width course banner
- Course title, description, metadata
- Expandable sections & lectures list with icons
- Edit/Manage action buttons

### 4. Create Course Page
- Clean form with: title input, description textarea, thumbnail upload area with drag-and-drop styling, dynamic sections & lectures builder (add/remove)
- Form validation feedback
- Save/publish buttons

### 5. Sample Data
Six courses with gradient thumbnail placeholders: Smart Cloud Kitchen Formula 2.0, Hackathon, Niche Clarity Blueprint, Content Marketing Mastery, Budget Setting Blueprint, AI Mastery — each with sections/lectures counts and "Published" status.

### Design System
- Primary: #7B61FF (purple)
- Background: #F8F9FA / white
- Success: green badges
- Cards: 14px border-radius, soft shadows
- Typography: Inter/system sans-serif, bold headings
- Smooth transitions on all interactive elements
